= ISO/AWI 25534-1 Part 1 — Vocabulary (PWI)

CalConnect working draft for the Digital Product Passport terminology
standard proposed as ISO 25534-1 Part 1 (Vocabulary), developed for
submission to ISO/IEC JTC 5.

== Build

[source,bash]
----
bundle install
metanorma sources/iso-25534-1-pwi/document.adoc
----

Artifacts: `document.pdf`, `document.html`, `document.xml`.

== Dataset

Term entries are generated from the Glossarist UniDPP dataset
(the UniDPP Glossarist dataset, 145 concepts) via `scripts/generate_terms.rb`.

== Form 4

The ISO NWIP Form 4 is at `form-4/FORM-4-DPP-VOCABULARY-NWIP.md`.
